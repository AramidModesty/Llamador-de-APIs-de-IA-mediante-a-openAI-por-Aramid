# Llamador de APIs de IA por Aramid Monsalve para estudiantes.

Bienvenido a la plantilla Llamador de APIs de IA por Aramid Monsalve.

Este repositorio esta hecho para ayudar a personas que conocen de programacion pero que nunca han tenido que lidiar con el llamado de modelos.
Debes preguntarte muchas cosas como las siguientes
- ¿Que tan cara es la entrada al mundo de la IA?
- ¿Como puedo estudiar este nuevo mundo sin dinero ni una computadora de la nasa?
- ¿Podemos hacer que una IA gratuita ejecute codigo por nosotros para su uso de estudio?

La respuesta a esas preguntas es que no tengo idea, para eso es este repositorio.
Es para estudiar a la inteligencia artificial y esta siendo hecho por un estudiante como tu.



    Nota importante: Cualquier intento de commit dejando la clave api adentro del sistema resultara en error y bloqueo de cualquier commit posterior, por lo cual se recomienda dejar a tu clave solo en .env o en algun archivo al que le pongas en .gitignore

## Este repositorio esta basado en la documentación de OpenAI.

https://developers.openai.com/api/docs/guides

Considera obtener una clave API en cualquiera de los sitios oficiales proveedores de llaves api:

https://platform.openai.com/api-keys

https://aistudio.google.com/app/apikey

https://openrouter.ai/

## Cuidado con el dinero, es un recurso valioso
No olvides definir el límite de tu clave API a cero para evitar que te pidan dinero.

Hay mas llamadores de API que solo openAI como son openrouter o aistudio de google,
si tienes tiempo deberias probarlos.
